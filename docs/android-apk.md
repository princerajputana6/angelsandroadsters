# Android APK (Capacitor)

This project ships as an installable Android app using **Capacitor**. Because
the app is a server-rendered Next.js app (API routes, JWT auth, MongoDB) that
runs on Vercel, the APK is a **native wrapper whose WebView loads the deployed
site** (`server.url` in `capacitor.config.json`). The full app works — API,
auth, DB — and the race-control offline features keep working inside the app
because the service worker + IndexedDB run under the live origin in the WebView.
It needs internet on first load, like any app that talks to a server.

- App id: `com.angelsandroadsters.app`
- App name: `Angels & Roadsters`
- Loads: `https://angelsandroadsters.vercel.app`
- Web shell (splash/offline fallback): `mobile/www/`
- Native project: `android/` (generated by Capacitor)

## Prerequisites to build the APK

You need a JDK (17) and the Android SDK. Easiest: install **Android Studio**
(it bundles a JDK and the SDK). This machine already has an Android SDK at
`~/Library/Android/sdk` (platforms 35/36, build-tools 35/36) but **no JDK**.

Set these (JDK 17 + SDK), e.g.:

```bash
export JAVA_HOME=/path/to/jdk-17        # or Android Studio's bundled JBR
export ANDROID_HOME=$HOME/Library/Android/sdk
export ANDROID_SDK_ROOT=$ANDROID_HOME
```

`android/local.properties` must point at the SDK:

```
sdk.dir=/Users/<you>/Library/Android/sdk
```

## Build a debug APK (installable for testing)

```bash
# from the repo root
npx cap sync android
cd android
./gradlew assembleDebug
```

Output: `android/app/build/outputs/apk/debug/app-debug.apk`

Share that file; installers must allow "Install unknown apps" on their phone.
A debug APK is fine for internal distribution/testing. It is NOT Play-Store
signed.

### Easiest path: Android Studio

1. Open the `android/` folder in Android Studio.
2. Let it sync Gradle (it manages the JDK + SDK for you).
3. **Build → Build Bundle(s)/APK(s) → Build APK(s)** → "locate" to find the APK.

## Release (signed) APK / AAB — for wider distribution

A debug APK is unsigned-for-release. For a store or long-lived distribution,
create a keystore and build a signed release:

```bash
keytool -genkey -v -keystore angels.keystore -alias angels \
  -keyalg RSA -keysize 2048 -validity 10000
```

Then configure signing in `android/app/build.gradle` (a `signingConfigs`
block referencing the keystore via `android/keystore.properties`, kept OUT of
git) and run `./gradlew assembleRelease` (APK) or `./gradlew bundleRelease`
(AAB for Google Play). Keep the keystore and its passwords safe and private —
never commit them.

## Pointing the app at a different URL

Edit `server.url` in `capacitor.config.json` (e.g. a staging URL), then
`npx cap sync android` and rebuild. To instead bundle a static site inside the
APK you would need a fully static export, which this server app does not support
without a backend rewrite.

## App icon & splash

Generated icons/splash live under `android/app/src/main/res/`. To regenerate
from source art, use `@capacitor/assets`:

```bash
npx @capacitor/assets generate --android   # expects assets/icon.png + assets/splash.png
```
